# astrbot_plugin_xiaohongshu

AstrBot 小红书插件：搜索 / 笔记 / 评论 / 点赞 / 收藏 / 关注 / 浏览养号。

## 功能

- 小红书笔记搜索、笔记详情、评论获取
- 点赞 / 收藏 / 关注 / 评论互动
- 浏览养号（模拟真实浏览行为）
- WUI 内嵌远程浏览器：真浏览器实时画面，点击拖动过验证
- 扫码登录 / Cookie 双通道登录
- 自动抓取 Cookie、Cookie 自动续期、掉线通知
- 浏览器依赖自动安装

## 安装

1. 在 AstrBot 插件市场 / 手动安装本插件
2. 在插件配置中填写 WUI 相关配置
3. 通过 WUI 面板扫码登录小红书

## 使用

- WUI 面板提供完整交互界面
- 支持命令触发核心功能

详见 _conf_schema.json。
